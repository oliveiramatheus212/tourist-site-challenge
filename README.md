# 🌏 Turismo em Busan | Landing Page

## 🇧🇷 Português

### 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma **Landing Page sobre Turismo em Busan**, criada como parte de um **exercício prático da formação Fullstack da Rocketseat**.

O objetivo do desafio foi colocar em prática os conceitos fundamentais de **HTML semântico** e **CSS**, focando na construção de layouts, organização de conteúdo e estilização visual, **sem o uso de JavaScript ou frameworks**.

### 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**

### 🎯 Objetivos do exercício

- Praticar a estruturação semântica do HTML
- Trabalhar com estilização utilizando CSS puro
- Desenvolver um layout de landing page responsivo
- Aplicar boas práticas de organização e legibilidade de código

### 🖼️ Descrição da página

A landing page apresenta informações turísticas sobre **Busan**, uma das principais cidades da Coreia do Sul, destacando:

- Pontos turísticos
- Cultura local
- Paisagens e atrações
- Layout visual atrativo e organizado

### 📚 Aprendizados

Com este exercício, foi possível reforçar conhecimentos como:

- Uso correto de tags semânticas
- Posicionamento de elementos com CSS
- Tipografia, cores e espaçamento
- Estruturação de uma landing page do zero

## 🇺🇸 English

### 📌 About the project

This project consists of developing a **Landing Page about Tourism in Busan**, created as part of a **practical exercise from Rocketseat’s Fullstack training program**.

The challenge focused on applying core concepts of **semantic HTML** and **CSS**, emphasizing layout creation, content organization, and visual styling, **without using JavaScript or any frameworks**.

### 🛠️ Technologies used

- **HTML5**
- **CSS3**

### 🎯 Exercise goals

- Practice semantic HTML structure
- Work with pure CSS styling
- Build a responsive landing page layout
- Apply best practices for code organization and readability

### 🖼️ Page description

The landing page presents tourist information about **Busan**, one of South Korea’s main cities, highlighting:

- Tourist attractions
- Local culture
- Landscapes and landmarks
- A clean and visually appealing layout

### 📚 Learnings

Through this exercise, it was possible to strengthen knowledge in areas such as:

- Proper use of semantic HTML tags
- Element positioning with CSS
- Typography, colors, and spacing
- Building a landing page from scratch
